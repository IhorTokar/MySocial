# NexusConnect (MySocial)

Соціальна мережа з гібридною стрічкою рекомендацій та аналізом ехо-камер — дипломний проєкт
«Розробка системи гібридних рекомендацій та аналізу спільнот у соціальній мережі на основі
графових алгоритмів та методів обробки природної мови».

## Що вміє

- **Соціальна мережа:** профілі, пости з тегами й фото, підписки, вподобання, коментарі з відповідями,
  збережені пости, особисті повідомлення (WebSocket), сповіщення, пошук.
- **Гібридна стрічка «Для вас»:** зважена сума п'яти складових — популярність, item-based
  колаборативна фільтрація, схожість у графі (node2vec), семантична близькість (вектори текстів),
  свіжість — і переранжування MMR для різноманітності. Ваги змінюються в адмін-панелі без перезапуску.
- **Аналіз спільнот:** спільноти Louvain / Leiden (Neo4j GDS), для кожної — echo-score: середнє
  тематичної однорідності, семантичної згуртованості й однорідності тональності; історія знімків
  і траєкторія користувача.
- **Адміністрування:** ролі, блокування, журнал дій, заявки на скидання пароля, експерименти
  (NDCG, MMR, валідація метрики ехо-камер).

## Склад

| Модуль | Технології | Призначення |
|---|---|---|
| `server/` | Java 21, Spring Boot 3.3, Spring Security (JWT), Flyway | REST API, WebSocket, рекомендації, аналіз спільнот |
| `client/` | JavaFX 21 | Настільний клієнт |
| `shared/` | Java | DTO, спільні для сервера й клієнта |
| `nlp-service/` | Python, FastAPI, sentence-transformers | Вектори текстів, тональність (`cardiffnlp/twitter-xlm-roberta-base-sentiment-multilingual`) |
| `tools/report/` | Python | Генератор даних, демонстрація, графіки для звіту |
| `docker-compose.yml` | PostgreSQL 16 + pgvector, Neo4j 5 + GDS, pgAdmin | Бази даних і NLP-сервіс |

## Запуск

Потрібні: JDK 21, Maven 3.9+, Docker з Compose. Для скриптів звіту — Python 3.10+ і `matplotlib`.

1. **Налаштування.** Скопіюйте шаблон і впишіть власні паролі та ключ JWT (щонайменше 32 символи):

   ```bash
   cp .env.example .env
   ```

2. **Бази даних і NLP-сервіс.** Перший запуск завантажує моделі (кілька хвилин):

   ```bash
   docker compose up -d
   ```

   Порти відкриті лише на цьому комп'ютері: PostgreSQL `5432`, Neo4j `7474`/`7687`,
   NLP `8001`, pgAdmin `5050`.

3. **Збірка та сервер.** Схему бази створює Flyway під час першого запуску:

   ```bash
   mvn -q install -DskipTests
   mvn -pl server spring-boot:run
   ```

4. **Клієнт** (в окремому терміналі):

   ```bash
   mvn -pl client javafx:run
   ```

5. **Перший адміністратор.** Зареєструйтеся в клієнті, потім надайте собі роль:

   ```bash
   docker exec -it social-pg psql -U social_app -d social_network \
     -c "UPDATE \"user\" SET role = 'admin' WHERE username = 'ваш_логін';"
   ```

   Після цього увійдіть знову — з'явиться адмін-панель.

## Дані для демонстрації та звіту

Сервер має працювати; пароль адміністратора скрипти запитують самі.

```bash
cd tools/report
python seed.py --admin ваш_логін                  # ~200 користувачів, 8 спільнот, пости, підписки
python demo.py --admin ваш_логін --experiments --scenario
python charts.py                                  # графіки → report-charts/
python seed.py --admin ваш_логін --only-cleanup   # прибрати згенероване
```

Згенеровані акаунти мають адреси `@seed.nexus.local` і пароль `password123`.

## Тести

```bash
mvn -pl server -am test
```

Інтеграційні тести піднімають власну PostgreSQL через Testcontainers — потрібен запущений Docker.
